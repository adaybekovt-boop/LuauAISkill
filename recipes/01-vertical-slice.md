# Первый вертикальный срез плейса

Маршрут: [tracks/new-place](../tracks/new-place.md).

## Постановка
Одна компактная карта, один интерактивный объект, понятное правило успеха/смерти и повтор. Цель — доказать взаимодействие систем, не впечатлить количеством Parts.

## Реализация
Определи root entrypoints и server state. Введи один client intent и server validation. Добавь minimal UI, spawn/respawn и очистку ресурсов. Затем второй клиент и наблюдение общего состояния. Сохрани scene/commit перед расширением.

## Приёмка
Повторить десять циклов вход→действие→смерть→возврат; проверить отсутствие duplicate handlers и расхождений двух клиентов.

## Что не делать
Не начинать с тысячи комнат и двадцати непроверенных систем. Не выдавать TODO inventory за реализованную экономику.

## Сдача
Файлы и setup, точные использованные API/источники, реальные тесты и screenshots/profiler по необходимости. NOT RUN для отсутствующего evidence.
