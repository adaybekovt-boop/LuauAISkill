# Взаимодействие с дверью или объектом

Маршрут: [tracks/network-combat](../tracks/network-combat.md).

## Постановка
Игрок отправляет намерение взаимодействовать. Конкретный объект и действие допустимы только в серверном контексте.

## Реализация
Используй пример SecureInteract как ограниченную основу. Опиши допустимый object registry, права, cooldown и дальность. Проверяй дешёвые условия до raycast. Финальный commit без yield либо с повторной validation после него. Клиент обрабатывает отсутствие Instance при ack.

## Приёмка
Цель за стеной, слишком далеко, удалена, не tagged, не anchored для static recipe; payload table/nil; flood; dead player; два одновременных запроса.

## Что не делать
Имя объекта, ID или ProximityPrompt не заменяют разрешение. Replicated position не доказывает честное движение.

## Сдача
Файлы и setup, точные использованные API/источники, реальные тесты и screenshots/profiler по необходимости. NOT RUN для отсутствующего evidence.
