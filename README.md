# LuauAISkill

A source-aware engineering skill and offline knowledge pack for modern Luau and Roblox Studio.

**Start with [`SKILL.md`](SKILL.md).** Russian installation and usage instructions: [`README_RU.md`](README_RU.md).

The pack separates authored engineering guidance, selected official documentation, reproducible upstream snapshots, and tests. Read [`sources/STATUS.md`](sources/STATUS.md) before making claims about freshness, corpus completeness, or runtime validation.

## Main sections

- `guide/`: 45 engineering chapters, routed through `guide/INDEX.md`.
- `reference/`: attributed language references and terminology.
- `examples/`: small Luau modules and Roblox integration examples.
- `recipes/`: implementation work orders and acceptance checks.
- `tools/`: offline search, source fetching, API lookup, legacy-pattern scanning and integrity checks.
- `tests/` and `evaluation/`: executable tooling tests, prepared Luau tests, Studio plans and model-evaluation tasks.
- `upstream/`: version-pinned official source snapshots **only when fetching has succeeded**. A catalog is not a downloaded corpus.

Documentation is not fine-tuning and does not guarantee a measured model-quality increase. Use the A/B evaluation protocol rather than promising an arbitrary percentage or universal high-end graphics.
