# Источники и происхождение

Материалы handbook/, tracks/, prompts/, recipes/ и templates/ написаны для этого пакета. Это не скопированные целиком веб-страницы и не официальный перевод Roblox. Для технических фактов указаны первичные источники. Реестр различает проверенную ссылку и наличие полного тела.

`reference/lighting-api-audit.json` — ручная транскрипция ограниченного набора полей одного pinned YAML; не полный API dump. Номер Studio и фактическая доступность у пользователя пока неизвестны. `sources/pins.json` фиксирует происхождение и дату проверки.

Веб-поиск и GitHub connector позволили прочитать страницы и metadata. Они не предоставили перенос всего корпуса в файловую среду этой сборки. Поэтому `upstream/` изначально содержит только честный статус NOT_DOWNLOADED, а не пустую папку, названную «полный справочник».

При последующем запуске downloader сохраняет оригинальные тела и лицензии отдельно от синтеза, не исполняет исходники и проверяет хеши. Документы Roblox/Luau и code snippets могут иметь разные условия лицензирования. Media и модели с отдельными Limited Use условиями не зеркалируются.

Количество файлов, индексированных chunks и ссылок — разные величины. Ни одна из них не является измерением качества модели. Любое A/B утверждение требует результатов evals/ и указания условий.
