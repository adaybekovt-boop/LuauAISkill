# TK • Luau + Roblox — база знаний для AI-агента

**Срез источников: 26 сентября 2026. Версия: 1.0.0.**

Это готовое ядро скилла: методичка на русском, маршруты чтения, примеры Luau, проверка API, локальный поиск, сценарии оценки и загрузчик официальной документации.

> **Граница поставки:** официальный Roblox/Luau корпус целиком в этот ZIP НЕ скачан. Сетевой доступ среды создания не позволил выгрузить репозитории. Здесь уже есть авторские материалы по проверенным первичным источникам, но это не офлайн-копия всех 2 279 страниц Roblox. Ссылки не посчитаны как скачанные страницы. Для получения исходных текстов предусмотрен `DOWNLOAD_FULL.cmd` / `tools/fetch_corpus.py`. Результат загрузки проверяется отдельно и не предполагается заранее.

## Начать прямо сейчас
Распакуй архив рядом со своим проектом. Передай агенту следующий текст, заменив путь:

```text
Используй ./LuauAISkill/SKILL.md как рабочий скилл для Roblox/Luau.
Сначала прочитай контракт и подходящий tracks/*.md. Не загружай весь архив в контекст.
До написания кода исследуй мой проект, версию Studio, RunContext и доступные API.
Для каждого нового API используй локальные источники или актуальную официальную документацию.
Не выдавай примеры этого пакета за протестированные в моей Studio.
После изменений запускай доступные проверки и разделяй PASS, FAIL и NOT RUN.
Задача: [конкретная задача проекта].
```

Это работает как папка проекта с `SKILL.md`; отдельный менеджер скиллов не обязателен. При наличии менеджера установи папку способом, который поддерживает именно твой агент, и сохрани относительные пути. Не копируй один SKILL.md без его handbook/tracks/reference. Автоматическое подключение в конкретный редактор этой сборкой не выполнялось.

## Поиск без интернета
Требуется Python **3.10+** со стандартным `sqlite3` с FTS5; дополнительные pip-пакеты не требуются. Готовая поисковая база входит в поставку. Из корня папки:

```bash
python tools/search.py "освещение PBR" --limit 6
python tools/search.py "DataStore UpdateAsync" --json
python tools/api_lookup.py Lighting.LightingStyle
```

Поиск возвращает файл и строки. Агент должен прочитать найденный раздел, а не принять короткий snippet за полную сигнатуру API. Поиск умеет несколько русско-английских синонимов; это keyword search, не обученная модель и не семантическая embedding-база.

## Получить большой официальный корпус
На Windows запусти `DOWNLOAD_FULL.cmd` из распакованной папки. Он не устанавливает Python и не требует секретов. Вручную:

```bash
python tools/fetch_corpus.py
python tools/release_pack.py --require-corpus --out ../LuauAISkill-Full.zip
```

По умолчанию загрузчик берёт **зафиксированные проверенные commits**, а не меняющийся main. Он скачивает английские текстовые материалы Roblox Creator Docs, включая Engine API YAML, и исходники документации сайта Luau. Видео, картинки, 3D-ассеты, переводы и компилятор не входят. Это намеренное ограничение текстовой базы, а не «весь интернет».

В `upstream/DOWNLOAD-REPORT.json` должны быть `complete_for_requested_sources: true` и отсутствие ошибок. Манифест каждого корпуса содержит ожидаемое/сохранённое количество файлов, URL, bytes, SHA256 и Git blob SHA. При частичном успехе программа возвращает ошибку; сохранённые файлы можно повторно использовать после проверки хешей. Нельзя назвать загрузку полной только потому, что появилась папка.

Для новых версий позже:

```bash
python tools/fetch_corpus.py --latest
python tools/build_index.py
```

`--latest` создаёт корпус под новым SHA. Старые корпуса не удаляются автоматически: сравни версии и убери старую из области индекса вручную, когда миграция проверена. Это предотвращает незаметную потерю воспроизводимого снимка, но поиск может находить несколько версий. Путь результата показывает SHA; выбери нужную явно.

Альтернативный путь для Roblox, когда Git tree API недоступен:

```bash
python tools/fetch_corpus.py --only roblox --method index
python tools/build_index.py
```

Этот вариант использует официальный индекс Markdown-страниц. Он **не является commit-пиннутым снимком**; доступность всех endpoint и полнота проверяются отчётом. Ошибка доступа не маскируется под отсутствие API. При ограничении GitHub API можно передать собственный read-only `GITHUB_TOKEN` через переменную окружения; он не требуется, не должен попасть в архив и отправляется только на GitHub API.

## Что читать
`tracks/INDEX.md` — выбор маршрута. `handbook/INDEX.md` — главы. `reference/` — миграции, свежесть и избранные API-метаданные. `examples/INSTALL.md` — куда ставить выбранные примеры. `evals/README.md` — как честно измерить эффект скилла на своей модели. `qa/BUILD-REPORT.json` — что действительно проверено при сборке.

Исходные англоязычные страницы остаются приоритетнее свободного перевода: имена свойств, enum, параметры и ограничения не переводятся. Русские главы — синтез и инженерные рекомендации, а не официальный перевод.

## Что этот пакет не обещает
Он не меняет веса модели и не доказывает заранее процент улучшения. Он не создаёт фотореализм одним скриптом, не заменяет art direction/ассеты и не гарантирует FPS. Примеры не проходили Roblox Studio runtime-проверку при создании пакета. Используй их как проверяемые заготовки, не как обещание готового production-framework.
