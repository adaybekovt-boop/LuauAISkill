# Roblox Engine API snapshot (offline)

Query with `python tools/roblox_api.py Class.Member` (see the tool's `--help`).

| File | What | Source / license |
|---|---|---|
| `globalTypes.d.luau` | Luau type definitions of the whole Roblox Engine API (classes, members, events, enums, datatypes, globals, deprecation attributes). Also used by `luau-lsp analyze --definitions=...` for typechecking. | Generated by the luau-lsp project, https://github.com/JohnnyMorganz/luau-lsp (`scripts/globalTypes.d.luau`), MIT License. Snapshot taken 2026-09-26. |
| `api-summaries.json.gz` | `{"Class.Member": "one-line official summary"}` for ~11k members. | Derived from the Roblox API docs dump in https://github.com/MaximumADHD/Roblox-Client-Tracker (`api-docs/en-us.json`), whose text comes from the Roblox Creator Documentation (prose CC BY 4.0, Roblox Corporation). Only the documentation strings are kept. |

The snapshot can go stale. `bash tools/setup_luau_toolchain.sh` downloads the current definitions into
`.toolchain/`, and the lookup tool prefers that copy. Members hidden by script security are not in the
definitions, and brand-new beta APIs may be missing. For those, check https://create.roblox.com/docs.
