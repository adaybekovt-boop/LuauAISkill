# Промпт для агента

Используй graphics track. Сначала inspect сцены и заполни VISUAL-BRIEF. Сделай одну контрольную комнату: правильные размеры и стыки → материалы → мотивированный свет → камера → мягкий postprocess. Не уничтожай чужие эффекты и не назначай protected properties по памяти. Сними сравнимые кадры и проверь low tier; без screenshot tool не оценивай невидимый результат как красивый. Затем распространяй проверенные решения по карте.
