# Промпт для агента

Проведи read-first инспекцию проекта. Начни с entrypoints, require graph, remotes, persistent writes и resource lifecycle. Найденные проблемы привяжи к реальным файлам/строкам и воспроизводимому сценарию. Не делай широкую перезапись ради стиля. Для каждого fix: воспроизводящий тест, минимальный patch, повторная проверка и риск регрессии. Отдельно перечисли source-only выводы и runtime-confirmed дефекты. Не объявляй отсутствие багов по одному lint pass.
