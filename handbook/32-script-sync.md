# 32. Script Sync, внешний редактор и источник истины

Авторский синтез; проверка первичных источников 26.09.2026. Не официальный перевод и не отчёт о выполненном Studio-тесте.

## Выбор рабочего процесса
Script Sync синхронизирует Luau-файлы и соответствующие scripts в Studio в обе стороны. Он удобен, когда код редактируется в IDE, а сцена остаётся в Studio. Он не является полным текстовым описанием DataModel. Для полного file-system source of truth существующий проект может использовать Rojo или другой проверенный pipeline; не включать одновременно два конкурирующих владельца одной ветви.

Перед подключением записать, какие folders синхронизируются, где резервная копия place и какой commit является baseline. Конфликт Keep Studio / Keep Disk — потенциально разрушительное решение, а не диалог, который агент закрывает наугад. Рассмотреть список добавлений, удалений и замен. Сначала пробный модуль, не главная папка с production-кодом.

## Суффиксы — не декоративные имена
В текущем Script Sync `name.luau` — ModuleScript, `.server.luau` — Script/Server, `.client.luau` — Script/Client, `.local.luau` — LocalScript, `.legacy.luau` — Script/Legacy, `.plugin.luau` — Script/Plugin. Нельзя переносить это правило на другой sync-инструмент без проверки его mapping. Ошибка суффикса меняет host и поведение запуска.

Синхронизируются поддерживаемые Script, LocalScript, ModuleScript и Folder. Tags, attributes и прочая сцена не считаются надёжно сохранёнными только по каталогу кода. Особенно опасно восстановить старые scripts, потеряв attributes, от которых зависят маршруты, настройки или права. Для таких метаданных нужен отдельный подтверждённый экспорт/manifest.

## Агент и Studio
File access даёт редактирование текста, но не просмотр результата. MCP может дать чтение game tree, тестирование и работу со сценой, если он реально подключён. Нельзя придумывать успешный MCP вызов. Перед крупным проходом выполнить безопасную проверку: прочитать дерево, изменить временный test script, увидеть ровно один ожидаемый лог, удалить тестовую сущность и проверить отсутствие хвостов.

Документация coding harness ещё описывает beta-включение Script Sync; отдельная feature-страница может описывать общий workflow без beta. Это не повод выдавать одну универсальную инструкцию для всех версий. Сверить фактическое меню/версию пользователя, не снимать sandbox ограничения ради удобства.
