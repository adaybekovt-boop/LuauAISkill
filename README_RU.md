# LuauAISkill — навык для ИИ-агентов: современный Roblox + Luau

Набор знаний и инструментов, который заставляет ИИ-агента писать **актуальный, безопасный и проверяемый** код для
Roblox Studio / Luau и грамотно ставить свет в сценах — вместо паттернов 2019 года, выдуманных API и фальшивых
«я протестировал». Срез: **2026-09-26**, API движка **0.740.19**, creator-docs `cc850a8`.

> Это документация + инструменты, а не дообученная модель. Эффект есть, только если агент читает нужные файлы;
> меряйте его через `evals/`, а не верьте процентам.

## Что внутри
| Путь | Содержимое |
|---|---|
| `SKILL.md` | точка входа: порядок работы, жёсткие правила, метки доказанности, маршрутизация, свежие факты |
| `tracks/` | 17 маршрутов по типам задач (сеть, данные, графика, бой, NPC…) — что загружать и в каком порядке |
| `handbook/` | 36 глав: `luau/`, `roblox/`, `graphics/` — плотные таблицы, деревья решений, проверенный код |
| `recipes/` | 20 игровых + 15 графических рецептов: архитектура, полный код, тесты, проверка на эксплойты |
| `examples/` | код рецептов в структуре Rojo (`examples/<проект>/<Сервис>/…`), общий `lib/`, тесты для Luau CLI |
| `references/` | каталог legacy→современное (89 записей), типичные ошибки ИИ, антипаттерны, отладка, лимиты, карта сервисов |
| `api/` | сгенерированный индекс API движка |
| `evals/` | проверочные задания по категориям, включая сломанный код и провокационные запросы |
| `tools/` | поиск по API, сканер legacy-кода, поиск по навыку, проверки, обновление источников |

Сам навык написан на английском (точные имена API, экономия токенов); агент отвечает пользователю на его языке.

## Установка
- **Claude Code**: скопируйте репозиторий в `~/.claude/skills/tk-luau-roblox/` (для себя) или в
  `<проект>/.claude/skills/tk-luau-roblox/` (для проекта).
- **Другие агенты**: укажите в инструкциях агента `SKILL.md` (или используйте `AGENTS.md`).
- Для `tools/api.py`, `tools/search.py`, `tools/scan_legacy.py` достаточно Python 3.10+ (индекс API уже в репозитории).

## Частые команды
```text
python tools/api.py Humanoid.LoadAnimation     # существует? устарело? чем заменить?
python tools/api.py Lighting.LightingStyle     # можно ли менять из скрипта? (нет: только Studio/плагины)
python tools/scan_legacy.py путь/к/коду        # найти устаревшие паттерны (только чтение)
python tools/search.py "session locking"       # поиск по навыку
```

## Что проверено, а что нет
- Весь Luau-код в Markdown и 70 файлов `examples/` прошли typecheck (luau-lsp 1.70.0, определения Roblox, strict,
  старый и новый солвер). 9 наборов тестов чистой логики (51 тест) выполнены в Luau CLI 0.740.
- Все упоминания API сверены с индексом; все ссылки на источники разрешаются; ссылки и якоря проверены.
- **В Roblox Studio и на живых серверах ничего не запускалось.** Для каждого рецепта есть таблица «How to test» —
  её нужно пройти вручную. Графические пресеты — стартовые значения арт-дирекшена: имена и типы свойств проверены,
  картинка скриншотами не подтверждена.

## Обновление под новые версии Roblox
`python tools/install_toolchain.py` → `python tools/fetch_sources.py --latest` → `python tools/build_api_index.py` →
`python tools/check_all.py` → просмотреть `git diff api/` и вручную обновить главы/каталог. Авторский текст
автоматически не перезаписывается.
